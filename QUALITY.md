The source positions are structurally valid and all setup and solution moves are legal. Every practice lesson uses a unique board position and side to move. Explicit opening sequences and the concept lesson's stalemate example were also replayed or checked. The engine audit is a bounded sanity check, not exhaustive proof of all defensive alternatives; see [Sources and methods](SOURCES.md).

Every final PDF was rendered, and 54 selected pages covering every chapter and the tightest layouts were visually inspected, with no layout defects identified in that sample. The searchable index was tested in a browser, and all local Markdown links were checked. Core text, diagrams, glyphs, solution text, and page boundaries were checked on the visual sample. This does not claim a human chess editor individually reviewed all 3,000 lessons.

SHA256SUMS.txt records the delivered files for copy and integrity verification. The checksum file excludes itself.
